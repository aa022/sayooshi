Sayonara o Oshiete builder

Turns your copy of Sayonara o Oshiete ~Comment te Dire Adieu~ and the English patch into a single self-contained game executable for Linux or Windows, with both languages inside.

Everything happens in this browser tab. Your files are not uploaded anywhere.

    Notes
    

      

    • Only the exact original files are accepted; they are checked by size and SHA-256 before anything else.
      • 

    • The result is about 570 MB. Building needs roughly 1.5 GB of free memory and takes under a minute.
      • 

    • Linux: make the download executable first (chmod +x sayooshi), then run it.
      • 

    • Windows: SmartScreen may warn about an unsigned program; choose "More info", then "Run anyway".
      • 

    • Saves go to the per-user data folder; a folder named saves next to the executable keeps
them there instead (portable mode).
